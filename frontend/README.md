# SynapLogix frontend

Web interface built with React, TypeScript and Vite, with an interactive Leaflet map on OpenStreetMap tiles.

Planned screens:

| Screen | Content |
|--------|---------|
| Home | Summary of the latest scenario and quick access to "Optimize" |
| Data | Import of products, destinations and orders, with filters, the scenario generator and validation errors |
| Fleet | Truck capacity, average speed, cost per km and maximum driving hours |
| Optimization | Scenario and algorithm selection, time limit and the "Optimize" button with a progress bar |
| Results | Map with one color per route, route and stop tables, KPIs, infeasible orders and CSV export |
| Compare | KPIs of several runs side by side |

The source code will live in `src/`.
